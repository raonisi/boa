# BOA CRM 스마트 상담 준비 카드 정책 (PR24)

## 목적

고객 상세 화면에서 **상담 직전**에 필요한 정보를 한 장의 카드로 요약합니다.

- 상담 전 고객 상황 빠른 파악
- 최근 이슈·다음 액션 누락 방지
- 성향에 맞는 접근 방향 정리
- 피해야 할 말·오늘 상담 목표 명확화

## 신규 데이터 생성 기능이 아님

PR24는 **기존 API 응답을 프론트에서 조합**하는 UI입니다.

- 신규 DB 테이블 없음
- 신규 migration 없음
- 신규 서버 API 없음
- activity_logs 추가 기록 없음

## 사용 데이터 출처

| 영역 | 출처 |
|------|------|
| 고객 상태 | `customers.get` |
| 상담기록 | `consultations.list` |
| 후속관리 | `followUps.listByCustomer` |
| 추천/경고 | `recommendations.customerContactReasons` |
| 태그·우선순위·다음 액션 | 고객 관리 메타 |
| 인수인계 | `customerHandoffNotes.listByCustomer` |
| 해지위험/청구 안내 | `retentionRisk.listByCustomer`, `claimGuidance.listByCustomer` |
| 연결 고객/소개 | `customerRelationships.list`, `customerReferrals.listByCustomer` |

## 정보 부족 표시 기준

- 최근 상담 없음 → “최근 상담기록 없음”
- 후속 없음 → “예정된 후속관리 없음”
- 태그 없음 → “고객 성향 태그 없음”
- 인수인계 없음 → “최근 인수인계 메모 없음”
- 상담 목표는 **단정하지 않고** 기존 상태 기반 추론, 불명확 시 “기타”

## 상담 안정 문구 기준

- 고객 선택권·설명 의무 존중
- 해지 고민 시 **유지 강요보다 확인·설명** 중심
- 상품 가입·투자 권유 문구 없음

## 금지 표현 (카드에 안내)

- “무조건 바꾸셔야 합니다”
- “이건 손해입니다”
- “오늘 안 하면 늦습니다”
- “무조건 유지하세요”
- “보험금 받을 수 있습니다” (단정)
- “수익 확정”

## 개인정보/민감정보 노출 방지

- 질병명, 주민번호, 계약번호 원문, 보험료 원문 **새로 노출하지 않음**
- 인수인계·상담 메모는 **1~2줄 요약** (`line-clamp-2`)
- console.log에 고객정보 출력 금지

## 권한 기준

기존 고객 상세 API RBAC를 그대로 따릅니다. 카드는 **이미 로드된 고객 범위 데이터만** 조합합니다.

## 모바일 사용 기준

- 기본: 요약 3줄
- “자세히 보기”로 3단 전체 구조 확장
- 버튼 `min-h-10` 이상 터치 영역

## UI 위치

고객 상세 → 상단 **상담 실행 요약** 아래, 탭(상담기록 등) 위

## 후속 PR 가능 항목

- 서버 측 상담 목표 추천 API (현재는 프론트 규칙 기반)
- 업무 리듬 리포트와 카드 연동 강화 (기존 API 부족 시)
