# BOA CRM 실적 지표 정책

BOA 지점관리 CRM의 실적 화면은 지점 내부에서 확인해야 하는 신규 영업 성과와 월납보험료 실적을 빠르게 보는 용도입니다.
유지/미유지 계약 상태의 세부 관리는 GA 본사 전산 기준으로 확인하며, BOA CRM에서는 중복 KPI로 관리하지 않습니다.

## 핵심 지표

### 신규 계약 건수

- 대표 필드: `newContractCount`
- 기존 호환 필드: `contractCount`
- 현재 기준: 기존 `performance.stats.contracted`와 동일한 신규 계약/전환 기준 값입니다.
- 기존 `contracted` 필드는 고객 상담상태가 `계약`인 고객 수로 유지합니다.
- 기존 화면의 모호한 `계약 건수` 문구는 `신규 계약`으로 표시합니다.

### 월납보험료 합계

- 대표 필드: `monthlyPremiumTotal`
- 기존 호환 필드: `monthlyPremiumSum`
- 현재 기준: 기존 월납보험료 실적 집계 로직을 유지합니다.
- 화면 문구는 `월납보험료` 또는 `월납보험료 실적`으로 표시합니다.

## 이번 PR에서 만들지 않는 지표

다음 지표는 이번 PR에서 추가하지 않습니다.

- 유지 계약 수
- 미유지 계약 수
- 전체 유효 계약 수
- 보유 계약 수
- 활성 계약 전체 수

이 값들은 GA 본사 전산의 계약 유지 상태가 더 정확한 기준이므로 BOA CRM에서 별도 KPI로 중복 관리하지 않습니다.

## 목표관리 호환 정책

- 기존 DB 컬럼 `contractCountGoal`은 삭제하지 않습니다.
- 새 DB 컬럼은 추가하지 않습니다.
- 화면에서는 `contractCountGoal`을 `신규 계약 목표`로 표시합니다.
- 목표 달성률은 `newContractCount` 기준으로 계산합니다.
- 월납보험료 목표는 기존 `monthlyPremiumGoal`을 그대로 사용합니다.

## 권한과 Scope

### branch_admin

- `scope=all`: 전체 지점 실적
- `scope=mine`: 지점장 본인이 담당하는 고객/계약 기준 실적

### sub_branch_admin

- 본인 산하 범위 기준 실적만 조회합니다.
- `scope=all` 직접 호출은 서버에서 차단됩니다.

### team_leader

- 본인 팀 범위 기준 실적만 조회합니다.
- `scope=all` 직접 호출은 서버에서 차단됩니다.

### member

- 본인 담당 고객/계약 기준 실적만 조회합니다.
- `scope=all` 직접 호출은 서버에서 차단됩니다.

### inactive/resigned

- 실적 API 접근을 차단합니다.

## 운영 해석 가이드

- 신규 계약: BOA CRM에서 관리하는 신규 영업 성과 기준입니다.
- 월납보험료 실적: 입력된 계약의 월납보험료 실적입니다.
- 유지/미유지 상태: GA 본사 전산에서 최종 확인합니다.
- BOA CRM은 상담, 후속관리, 신규 계약 성과, 월납보험료 실적을 연결해 팀원의 실행력을 높이는 데 집중합니다.
