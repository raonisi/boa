# 고객 일괄 등록 양식 정책

## 목적

고객 DB 일괄 등록 양식은 파일럿 운영자가 Windows Excel에서 바로 열어도 한글이 깨지지 않고, 역할별 배정 정책을 혼동하지 않도록 관리합니다.

## 파일 형식

- 기본 제공 형식은 `.xlsx`입니다.
- CSV 보조 다운로드는 UTF-8 BOM을 포함해 제공합니다.
- 업로드는 `.xlsx`와 `.csv`를 지원합니다.

## 필수 컬럼

아래 3개 컬럼만 필수입니다.

- 이름
- 생년월일
- 연락처

하나라도 누락되면 해당 행은 오류로 처리합니다.

## 선택 컬럼

아래 컬럼은 선택값입니다.

- 성별
- 지역
- 예상보험료
- 통화가능시간
- 유입경로
- 상담상태
- 메모

상담상태를 비워두면 서버에서 `미상담`으로 등록합니다.

## branch_admin 양식

지점장 양식은 아래 컬럼을 사용합니다.

```text
이름,생년월일,연락처,성별,지역,예상보험료,통화가능시간,유입경로,상담상태,메모,담당자
```

- `담당자`를 입력하면 해당 담당자에게 고객을 배정할 수 있습니다.
- `담당자`를 비우면 기존 등록 정책에 따라 처리합니다.
- `부지점장`, `팀` 컬럼은 조직 트리 구조와 혼동을 줄이기 위해 양식에서 제공하지 않습니다.

## 비관리자 양식

부지점장, 팀장, 팀원 양식은 아래 컬럼을 사용합니다.

```text
이름,생년월일,연락처,성별,지역,예상보험료,통화가능시간,유입경로,상담상태,메모
```

- 업로드한 고객은 본인 고객으로 자동 등록됩니다.
- `담당자` 컬럼은 사용하지 않습니다.
- 파일에 임의로 담당자 관련 컬럼을 넣어도 타인에게 배정할 수 없습니다.

## 운영 주의사항

- 실제 고객정보로 양식 테스트를 하지 않습니다.
- 테스트 데이터는 `[TEST]`로 식별 가능하게 작성합니다.
- 업로드 batch 기록과 취소 정책은 기존 정책을 유지합니다.
- 운영 DB에서 reset, drop, hard delete를 수행하지 않습니다.
- 비밀값과 민감정보를 양식, 로그, 문서에 포함하지 않습니다.
