# 신규 로드맵 PR5. 영업 퍼널·성과 리포트

이 문서는 새 로드맵 기준의 **신규 PR5** 작업 범위를 설명한다. 기존 HANDOFF의 과거 PR5인 “상담기록 UX + 고객 우선순위 + 태그”와 다른 작업이다.

## 목적

PR4 모바일 3터치 업무 완료 UX 이후, 실제 처리 행동이 영업 성과로 어떻게 이어지는지 확인할 수 있도록 DB 보유, 상담, 후속관리, 계약, 월납보험료 실적 흐름을 한 화면에서 보여준다.

## 포함 범위

- 영업 퍼널 요약
- 성과 KPI 카드
- 전환율 분석
- 팀원 성과 비교
- 병목 진단
- 기간, 조직, scope, 성과 기준 필터
- 모바일 세로 카드형 퍼널 UI

## 제외 범위

- PR6 운영 리스크 센터
- 유지/미유지 계약 지표
- 계약 유지율/해지율 자동 계산
- 고객 상태 자동 변경
- 후속관리 자동 생성
- 다운로드/export
- 푸시 알림 payload 변경
- Play Store 배포
- 운영 DB reset/drop/hard delete

## 퍼널 단계 매핑

| 단계 | 기준 |
| --- | --- |
| DB 보유 | 조회 범위 내 활성 고객 DB |
| 상담 전 / 미상담 | 상담상태가 미상담이거나 상담기록이 없는 고객 |
| 상담 진행 | 상담상태가 미상담이 아니거나 상담기록이 있는 고객 |
| 후속관리 예정 | 기간 내 예정된 미완료 후속관리 |
| 후속관리 완료 | 기간 내 완료된 후속관리 |
| 계약 등록 | 기간 내 신규 계약 |
| 월납보험료 실적 발생 | 기간 내 신규 계약 월납보험료 합계 |

## 권한/scope

권한 검증은 프론트 필터 숨김이 아니라 `salesReports` 서버 라우터에서 수행한다.

- `branch_admin`: 전체, 부지점, 팀, 개인, 내 DB 조회 가능
- `sub_branch_admin`: 산하 범위만 조회 가능
- `team_leader`: 본인 팀/산하 팀원 범위만 조회 가능
- `member`: 본인 데이터만 조회 가능, 타인 랭킹 미노출
- `inactive` / `resigned`: `activeUserProcedure`에서 차단

## 지표 기준

- 신규 계약 수: 기간 내 계약 rows 중 철회/해지/실효가 아닌 계약
- 월납보험료 실적: 기간 내 신규 계약의 `monthlyPremium` 합계
- 상담기록 수: 기간 내 상담기록 수
- 후속관리 완료율: 기간 내 생성 또는 예정된 후속관리 대비 완료 건수
- 목표 대비 달성률: 선택한 기준이 `월납보험료`면 월납 목표, `신규 계약`이면 계약 수 목표 기준
- 0분모 전환율: `NaN` 또는 `Infinity`를 표시하지 않고 `0%`로 처리

기간 필터는 한국 현장 운영일 기준으로 해석한다.
- 오늘: Asia/Seoul 00:00:00 ~ 23:59:59.999
- 최근 7일: 오늘 포함 최근 7개 한국 영업일
- 이번 달: Asia/Seoul 기준 1일 00:00:00 ~ 말일 23:59:59.999
- 지난달: Asia/Seoul 기준 지난달 1일 00:00:00 ~ 말일 23:59:59.999
- 직접 선택: 시작일/종료일 모두 포함

전환율 계산식:
- DB 대비 상담 전환율 = 상담 진행 고객 수 / DB 보유 수
- 상담 대비 계약 전환율 = 계약 발생 고객 수 / 상담 진행 고객 수
- 후속관리 완료율 = 후속관리 완료 수 / 후속관리 생성 또는 예정 수
- 후속관리 완료 대비 계약 전환율 = 계약 발생 고객 수 / 후속관리 완료 수

## 개인정보/로그

이번 PR은 조회 리포트 중심이므로 새 `activity_logs` 기록을 만들지 않는다. 리포트 응답에는 상담기록 본문, 전화번호, 질병명, 상품명, 보험료 전문 같은 민감정보를 포함하지 않는다.

## 운영 해석 리스크

퍼널 계산은 기존 CRM 데이터의 상태값과 날짜 기준을 그대로 사용한다. 운영 데이터에서 “계약 등록일”, “상담 진행”, “후속관리 완료”의 현장 입력 습관에 따라 퍼널 해석이 달라질 수 있으므로 파일럿 운영 검수에서 지표 의미를 확인해야 한다.

## 운영 UAT 체크리스트

1. branch_admin으로 `/analytics` 접속 후 전체 리포트가 보이는지 확인한다.
2. 기간 필터를 오늘, 최근 7일, 이번 달, 지난달, 직접 선택으로 바꿔 지표가 갱신되는지 확인한다.
3. 조직 필터에서 부지점, 팀, 개인 범위를 선택해 권한 범위 내 데이터만 보이는지 확인한다.
4. member 계정으로 접속해 본인 리포트만 보이고 팀원 성과 비교가 숨겨지는지 확인한다.
5. 모바일 화면에서 퍼널이 세로 카드형으로 깨짐 없이 표시되는지 확인한다.
6. Android 내부 APK WebView에서 `/analytics` 접근과 카드 스크롤이 정상인지 확인한다.
7. 병목 진단 카드가 “현재 병목”, “추천 행동”, “확인할 고객군”을 보여주는지 확인한다.
8. PR6 운영 리스크 센터 항목이 섞이지 않았는지 확인한다.
