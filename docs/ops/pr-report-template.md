# PR Report Template

Use this template to keep PR handoffs short, consistent, and reusable for the next Codex task.

```text
[BOA CRM PR SUMMARY]

Task:
Branch:
Scope:
Changed files:
Runtime behavior changed:
DB/API/RBAC changed:
Tests run:
Failed tests:
Known limitations:
Risk:
Rollback:
Next recommended task:
```

## Guidance

- Keep the next task prompt short.
- Do not paste long logs.
- For failed tests, include only the key error line.
- Always state whether runtime behavior changed.
- Always state whether DB/API/RBAC changed.
- Include rollback criteria.
- Include one next recommended task when useful.
