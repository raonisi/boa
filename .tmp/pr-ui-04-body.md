## Summary

- 통합 검색 화면을 고객 업무 시작점 수준의 프리미엄 UI로 재구성하고 한국어 문구를 통일
- 고객·계약 검색 결과를 섹션별 카드로 구분하고 빠른 실행(등록/상담/후속/일정/계약)을 정리
- 기존 모바일 검색 hotfix(`search` 쿼리·페이지네이션) 유지, API/RBAC 변경 없음

## Test plan

- [ ] 통합 검색 진입 시 검색 헤더·빠른 실행·최근 고객 안내가 표시되는지 확인
- [ ] 고객명/연락처 검색 시 고객 결과·계약 결과 섹션이 구분되어 표시되는지 확인
- [ ] 검색 결과 카드에서 고객 상세·빠른 실행(상담/후속/일정/계약)이 동작하는지 확인
- [ ] 검색 결과 없음·로딩·오류 상태 문구가 한국어로 표시되는지 확인
- [ ] 작은 Android 화면에서 긴 고객명/상품명 overflow 없이 표시되는지 확인
- [ ] Dashboard·CustomerDetail·Global Search 진입 회귀 없음 확인
- [ ] WebView fallback(상담 기록·고객 등록) 회귀 없음 확인
