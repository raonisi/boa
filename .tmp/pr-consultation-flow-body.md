## Summary

- CustomerDetail 360을 실제 보험 상담 순서(고객 요약 → 오늘 확인 → 최근 상담 → 진행 관리 → 계약 → 다음 액션)로 재배치
- 상담 전 체크리스트 카드와 하단 다음 액션 영역을 분리해 현장 상담 흐름을 강화
- API/RBAC 변경 없이 UI/UX 재구성 및 한국어 문구 정리

## Test plan

- [ ] 고객 상세 진입 시 섹션이 상담 순서대로 스크롤되는지 확인
- [ ] 오늘 확인할 항목에 다음 조치·연체 후속·오늘 일정이 표시되는지 확인
- [ ] 최근 상담 기록·진행 중인 관리·계약 요약·다음 액션 CTA 동작 확인
- [ ] 상담 기록(WebView)·후속·일정·계약·전화/문자 회귀 없음 확인
- [ ] 작은 Android 화면 overflow 및 dark mode 가독성 확인
