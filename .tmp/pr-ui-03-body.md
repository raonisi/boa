## Summary

- 고객 상세 360 화면을 상담·후속·일정·계약 중심 허브로 재구성하고 프리미엄 CRM 톤의 카드·섹션 UI로 고급화
- 사용자 노출 문구를 한국어로 통일하고 로딩/오류/빈 상태 메시지를 상담 현장에 맞게 개선
- 기능·API·RBAC 변경 없이 UI/UX 재배치와 가독성 개선에만 집중

## Test plan

- [ ] 고객 상세 진입 시 프로필 요약·다음 액션·상담/후속/일정/계약 섹션이 스크롤 흐름대로 표시되는지 확인
- [ ] 상담 기록 추가·후속 등록·일정 등록·계약 등록·전화/문자 CTA가 기존과 동일하게 동작하는지 확인
- [ ] 빈 상태(상담/후속/일정/계약) 및 로딩/오류 UI 문구가 한국어로 표시되는지 확인
- [ ] 작은 Android 화면에서 긴 고객명·상품명·상담 요약 overflow 없이 표시되는지 확인
- [ ] dark mode에서 카드·배지·텍스트 가독성 확인
- [ ] Dashboard·Global Search에서 고객 상세 진입 회귀 없음 확인
- [ ] WebView fallback(상담 기록 등) 회귀 없음 확인
